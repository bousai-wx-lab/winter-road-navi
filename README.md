# 冬道そなえナビ / Winter Road Navi

日別の平均最低気温の傾向と全国の道路を重ねて確認する、Bousai Wx Labの公開ツールです。

公開URL: https://bousai-wx-lab.github.io/winter-road-navi/

## 現在の公開範囲

国土地理院のベクトルタイルから道路を読み込み、次の2種類を別の色で表示します。

- 高速道路：氷を思わせる青緑色
- 一般道路：濃い青色。拡大するほど細い道路を表示

地図の移動、拡大・縮小、道路種別の表示切替、全国表示への復帰、道路のクリック確認ができます。

Bousai Wx Labの保存済みロゴを使い、「周囲より低い地形チェッカー」の情報設計を基準にしたヘッダーとフッターへ統一しています。氷・雪を連想する寒色の画面から、Bousai Wx Labブログと公式X `@bousai_wx_lab` を新しいタブで開けます。使い方ページへのリンクは、案内記事を用意するまで表示しません。

平年の気温分布を表示しますが、積雪、凍結、通行規制、渋滞、経路案内は表示しません。現在の道路状況や安全を示す地図ではありません。

## 日別最低気温の1kmメッシュ

1991〜2020年の各暦日の平均最低気温を、気象庁の日別平年値917地点と国土数値情報の標高から独自算出・独自内挿した格子です。公式の日別1kmメッシュではありません。最大100km以内20地点の標高補正付き局所回帰と距離加重残差を用います。元の共有データ基盤の確定版から表示用派生物だけを作り、原資料・生成器・監査原本は公開repoへ複製しません。

初期日は1月15日。月・日選択、366日スライダー、前後1日ボタン、1年を一周する再生（目標約12秒／36秒）、気温の表示切替・濃さ変更ができます。2月29日を含む閏年の暦順とし、12月31日の次は1月1日です。2月29日は気象庁が前後日から作った公式地点値に基づく格子を使用します。再生は準備後に全日を順に表示し、端末が遅い場合は日を飛ばさず時間を延ばします。準備中の中止、再生停止、日付操作、タブを隠す操作で再生を止めます。

### 数値・座標・表示の対応

- 格子は標準地域3次メッシュ387,717件。383,497件を着色し、100km以内に採用観測所がない4,220件は欠測です。未収録の陸地がないとは保証しません。
- 緯度間隔1/120度、経度間隔1/80度の元格子境界をそのままMercator座標へ投影します。基盤のJGD2000格子をWeb地図の経緯度として扱い、地殻変動の補正はしません。観測点をぼかした面、月値の時系列補間、空間解像度の間引きは使いません。
- 原値0.1℃を1℃幅の表示階級へ射影し、元の小数値は配信しません。bin= floor(℃)+41、bin 0は欠測、1〜81は−40℃以上41℃未満。マイナス値も切り捨て方向を統一します。選択地点は南西閉・北東開の格子で検索し、色と同じ「○℃以上○℃未満」を表示します。
- GPUで格子ごとの矩形を描き、道路より下へ1回だけ透明度を適用します。欠測は透明で0℃と区別。凡例は描画と同じ色関数を使います。
- 日別データはJSONの階級・連続数の組をgzipで圧縮し、格子は緯度行・経度開始列・連続数で保持します。`data/temperature/manifest.json` が出典、利用条件、元データhash、暦日、格子数と各表示ファイルのhash・容量を所有します。
- 通常は選択日だけ読み込み、最大40日をメモリに保持します。再生時は全366日を準備し、展開済み階級だけで約142MBを一時使用します。停止後は40日以内へ戻します。通信中は前の日の色を新しい日付で見せず、失敗時は気温面を隠し再試行できます。通信失敗を欠測や0℃へ変えません。
- 日別LOOCVのRMSEは約0.49〜1.30℃。1kmは格子の大きさであり、局所精度の保証ではありません。盆地・沿岸・高標高・離島では数℃の誤差が残り、冷気湖、斜面向き、土地利用などは表現しません。一部の公式地点値は30年未満の統計です。

予報・実況・路面温度ではなく、凍結・通行可否・安全を判定しません。気温0℃という色境界も路面凍結の判定境界ではありません。気象庁と道路管理者の最新情報を別途確認してください。

出典・利用条件：

- https://www.data.jma.go.jp/stats/data/mdrr/normal/index.html
- https://www.jma.go.jp/jma/kishou/info/coment.html
- https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-G04-a.html
- https://nlftp.mlit.go.jp/ksj/other/agreement.html

原資料を加工した独自表示であり、出典機関が作成・認定したものではありません。基準期間固定の気候値なので日次更新はしません。基盤データの確定版が更新されたときだけ、表示派生変換、全日対応照合、公開manifestと安全検査、代表日のPC・スマートフォン操作確認を経て更新します。

## データと表示

- 道路：国土地理院「地理院地図Vector（試験公開）」の `road` レイヤー
- 背景：国土地理院「淡色地図」タイル
- 道路区分：`motorway`、`rdCtg`、`ftCode` を使った本ツール独自の表示区分
- 地図描画：MapLibre GL JS 6.10.0

地理院地図Vectorは試験提供で、URL、属性、データ構成が変更される場合があります。公式案内では2026年9月16日に全国データを2026年7月1日時点へ更新したとされています。

- https://maps.gsi.go.jp/development/vt.html
- https://maps.gsi.go.jp/development/ichiran.html
- https://www.gsi.go.jp/LAW/2930-index.html

国土地理院のデータをBousai Wx Labが独自に区分・着色して表示しています。国土地理院が本ツールの区分を作成・認定したものではありません。

## 通信とプライバシー

この版は、現在地、住所、自由入力、Cookie、Web Storage、アクセス解析を使用しません。表示状態を端末やURLへ保存しません。

地図を動かすと、表示範囲に応じたタイルを国土地理院へ直接要求します。この通信では、IPアドレス、要求したタイルURL、時刻、一般的な通信情報が配信元に伝わり得ます。GitHub Pagesへのアクセス情報はGitHub側の通信記録に残り得ます。

ブログとXには、利用者がヘッダーまたはフッターのリンクを押した時だけ移動します。

## ローカル確認

```sh
python3 -m http.server 8000
```

`http://127.0.0.1:8000/` を開きます。`file:` URLではWeb Workerやモジュールの制約により動きません。
