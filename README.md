# 冬道そなえナビ / Winter Road Navi

日別の平均最低気温・平均最高気温を切り替え、日最深積雪の平年推定値と全国の道路を重ねて確認する、Bousai Wx Labのツールです。

公開URL: https://bousai-wx-lab.github.io/winter-road-navi/

## 現在の公開範囲

国土地理院のベクトルタイルから道路を読み込み、同じ地図上で選択日の1km格子の気温に応じて道路線を着色します。最低気温モードと最高気温モードを切り替えられます。

- 高速道路：太い線。5℃超は青緑色
- 一般道路：細い線。5℃超は濃い青色。拡大するほど細い道路を表示

0℃以下は赤、0℃超〜2℃以下はだいだい、2℃超〜5℃以下は黄色です。気温がない区間は灰色で、5℃超と区別します。道路を元の1km格子境界で分割して着色し、日付変更・再生に連動します。道路種別は太さで区別し、気温面の表示・濃さとは独立して道路を着色します。格子境界の分割は表示中の道路タイルだけをブラウザ内で処理し、全国の道路データを事前取得しません。

積雪面は初期状態でOFFです。同じ日付の積雪を別のON/OFFと濃さで調整でき、雪域と1・5・10・20・50・100cm以上となる格子の境界を細い実線で表示します。地図の移動、拡大・縮小、道路種別の表示切替、全国表示への復帰、道路のクリック確認ができます。全国表示まで縮小しても高速道路の線と気温区分の着色を保ちます。一般道路は従来どおり拡大した画角で表示します。

「マウス位置の気温・積雪を表示」は初期状態でONで、OFFにするとツールチップを消します。地図上のカーソル位置（タップ時はその位置）について、同じ選択日の1km格子の選択中の平均最低気温または平均最高気温と日最深積雪を表示します。積雪面のON/OFFと独立して選択日の積雪階級を1日分だけ取得し、積雪が現象なし、現象あり0cm、欠測の場合も区別します。公開用データは気温が1℃幅、積雪が複数の深さ帯に圧縮された表示階級なので、ツールチップもその階級を示し、元の小数値や1cm単位の元値を装いません。予報・実況・路面状態ではありません。

Bousai Wx Labの保存済みロゴを使い、「周囲より低い地形チェッカー」の情報設計を基準にしたヘッダーとフッターへ統一しています。氷・雪を連想する寒色の画面から、Bousai Wx Labブログと公式X `@bousai_wx_lab` を新しいタブで開けます。使い方ページへのリンクは、案内記事を用意するまで表示しません。

平年の気温と積雪深の推定分布を表示しますが、道路上の積雪、凍結、通行規制、渋滞、経路案内は表示しません。現在の道路状況や安全を示す地図ではありません。

## 日別最低気温の1kmメッシュ

1991〜2020年の各暦日の平均最低気温を、気象庁の日別平年値917地点と国土数値情報の標高から独自算出・独自内挿した格子です。公式の日別1kmメッシュではありません。最大100km以内20地点の標高補正付き局所回帰と距離加重残差を用います。元の共有データ基盤の確定版から表示用派生物だけを作り、原資料・生成器・監査原本は公開repoへ複製しません。

表示期間は9月15日から翌6月15日までの275日で、初期日は9月15日です。月・日選択、期間内スライダー、前後1日ボタン、冬季全体の再生（目標約12秒／36秒）、気温の表示切替・濃さ変更ができます。12月31日の次は1月1日で、2月29日も含みます。9月15日の前と6月15日の後へは進まず、再生は9月15日から6月15日まで進んで止まります。2月29日は気象庁が前後日から作った公式地点値に基づく格子を使用します。端末が遅い場合は日を飛ばさず再生時間を延ばします。再生準備中の中止、再生停止、日付操作、タブを隠す操作で再生を止めます。

### 数値・座標・表示の対応

- 格子は標準地域3次メッシュ387,717件。383,497件を着色し、100km以内に採用観測所がない4,220件は欠測です。未収録の陸地がないとは保証しません。
- 緯度間隔1/120度、経度間隔1/80度の元格子境界をそのままMercator座標へ投影します。基盤のJGD2000格子をWeb地図の経緯度として扱い、地殻変動の補正はしません。観測点をぼかした面、月値の時系列補間、空間解像度の間引きは使いません。
- 原値0.1℃を1℃幅の表示階級へ射影し、元の小数値は配信しません。bin= floor(℃)+41、bin 0は欠測、1〜81は−40℃以上41℃未満。マイナス値も切り捨て方向を統一します。選択地点は南西閉・北東開の格子で検索し、色と同じ「○℃以上○℃未満」を表示します。
- GPUで格子ごとの矩形を描き、道路より下へ1回だけ透明度を適用します。欠測は透明で0℃と区別。凡例は描画と同じ色関数を使います。
- 日別データはJSONの階級・連続数の組をgzipで圧縮し、格子は緯度行・経度開始列・連続数で保持します。`data/temperature/manifest.json` が出典、利用条件、元データhash、暦日、格子数と各表示ファイルのhash・容量を所有します。
- 道路の気温区分は、丸めた1℃階級から推測せず、元の0.1℃値から0.0℃・2.0℃・5.0℃を含めて判定します。日別ファイルの `road_runs` が同じ格子順の区分を保持します。道路形状の格子分割は日付に依存せず、日付変更では気温区分だけを更新します。
- 初期日を表示した後、表示対象の275日を選択日に近い順で並行して裏読みします。配信データは合計約36.0MB、気温階級と2bit化した道路区分の配列だけで最大約133MBをメモリに保持します。準備中は進捗を示し、日付操作で未準備の日を選んだ場合は連打による不要な通信を短く間引いてその日を優先します。準備済みの日への移動には追加通信が不要です。未準備の選択日を待つ間は前の日の地図を残し、表示中の日付と準備中の日付を明記します。失敗時は気温面を隠し道路を従来色へ戻して再試行できます。通信失敗を欠測や0℃へ変えません。タブを隠すと裏読みを一時停止し、戻ると再開します。ページを閉じるとメモリ内の準備結果は失われ、ブラウザへの永続保存は行いません。公開派生物の原ファイルは366日分を維持し、表示と裏読みだけを冬季に限定します。
- 日別LOOCVのRMSEは約0.49〜1.30℃。1kmは格子の大きさであり、局所精度の保証ではありません。盆地・沿岸・高標高・離島では数℃の誤差が残り、冷気湖、斜面向き、土地利用などは表現しません。一部の公式地点値は30年未満の統計です。

予報・実況・路面温度ではなく、凍結・通行可否・安全を判定しません。気温0℃という色境界も路面凍結の判定境界ではありません。気象庁と道路管理者の最新情報を別途確認してください。

## 最低気温・最高気温の切り替え

左パネルの「表示する気温」で最低気温モードと最高気温モードを選びます。初期状態は最低気温です。同じ選択日・地図・濃さ・面のON/OFFを保ち、気温面、道路着色、クリック地点、位置ツールチップ、見出しと凡例の名称を同じモードへ連動させます。積雪は同じ日付のままで、気温種別によって値を変えません。モード変更時は再生を止め、準備中は前の表示日の気温種別を明記します。遅れて届いた旧モードの応答で新しい選択を置換しません。

最高気温は1991〜2020年の日最高気温の**日別平年値**を基にした独自推定で、公式の日別1kmメッシュではありません。916地点の公式日別変化を距離加重で内挿し、既存の月別1km最高気温推定値へ加算した確定版を利用します。最低気温へ一定差を加えたものではありません。格子は最低気温と完全に同じ387,717件で、4,220件は欠測です。元値0.1℃を気温面の1℃帯へ変換し、道路は同じ0℃・2℃・5℃の境界を元値から判定します。

表示用派生物は `data/temperature-max/manifest.json` と366日分のファイルが所有します。表示・再生は最低気温と同じ冬季275日に限定します。各モードのデータを別のメモリキャッシュへ保持し、裏読みは選択中のモードだけで進めます。切替時に既に進行中の取得は完了する場合があります。最高気温の日別ファイルは約38.5MB（冬季の実取得量はmanifestの該当275日分）。両モードの冬季を準備した場合、気温帯と道路区分の配列は合計最大約266MBとなり、永続保存はしません。

最高気温の推定は、月別基準の誤差や局地地形・土地利用の影響を含みます。地点の日別変化の交差検証は、日別気温全体の独立した精度保証ではありません。最低気温の検証誤差を最高気温へ流用しません。予報・実況・路面温度・凍結・安全判定には使いません。共有側の原資料、配列、生成器、QAは変更・複製せず、表示階級と道路区分だけを使います。

## 日最深積雪の1kmメッシュと等値線

1991〜2020年の「その日の最大積雪深」の平年値を、気象庁の地点別日別・月別平年値と既存の月別1km推定値から独自推定した共有データに基づき表示します。日平均積雪深、当日の観測値、降雪量、道路上の雪ではありません。気象庁の公式日別1kmメッシュでもありません。元の共有データと生成器は公開repoに置かず、このツールに必要な9月15日〜翌6月15日の275日だけ、表示階級と閾値境界へ変換します。

- 現象なしは無色、現象あり0cmは白、約350cm以上は黒として細かな階級で濃淡を表示します。「1cm以上のみ表示」をONにすると現象あり0cmも無色になり、正の最小階級である1cmが白になります。OFFに戻すと0cmも表示します。判定不能・欠測も無色で、クリック時に現象なしと区別して示します。現行の元配列は整数cmで、0.1cmなどの小数の積雪深は保持していません。これはデータの保存精度であって、自然界に1cm未満の積雪がないという意味ではありません。元の1cm単位の値は配信しません。
- 地上気象観測の公式日別平年値は「現象なし」と「現象あり0cm」を区別しますが、アメダスの0cmは曖昧です。後者を不在の根拠にせず、既知の観測点から全国1kmの現象区分を独自推定します。境界は公式線ではありません。
- 実線は現象の有無、および隣接する現象あり1km格子が1・5・10・20・50・100cmの閾値をまたぐ**元格子境界**です。0cm除外中は現象の有無の境界線を隠します。1画素幅で、曲線補間はしません。階段状に見える場合があり、判定不能・欠測格子や未収録の外側との境界は引きません。異なる閾値線が同じ格子境界で重なることがあります。
- 積雪面は気温面より上、道路より下に置きます。気温面と積雪面は独立してON/OFF・濃さ調整でき、両方をONにすると色が混ざります。積雪は初期状態でOFFのため、従来の気温・道路表示は変わりません。
- `data/snow/manifest.json` は公開表示ファイル275件の出典、元データ版のハッシュ、単位、表示階級、各ファイルのハッシュと容量を示します。全ファイル約17.2MBを積雪面ON時だけ選択日に近い順で裏読みし、メモリへ保持します。積雪面OFFでもツールチップONなら選択日の1件だけ取得します。永続保存はしません。再生中は必要な積雪データの準備完了を待ちます。取得や検証に失敗した日付は雪なしに置き換えず、積雪面を隠してエラーを示します。気温・道路は継続して操作できます。
- 元の1km格子は387,717件です。積雪の元推定には328地点の公式日別平年値を用い、近傍地点のない正値格子は欠測です。1kmは格子サイズであって局所精度の保証ではなく、山地、盆地、沿岸、雪域端などで大きな誤差があり得ます。月別の地形的な分布にも誤差があるため、地点値の検査だけで全国1km値の精度を保証しません。

雪の有無や深さの色と線は平年の参考分布であり、運転可否、チェーンや冬タイヤの要否、除雪状況を判断するものではありません。出発前に最新の気象庁情報と道路管理者の通行・規制情報を確認してください。

### 既知の積雪推定上の制約

2026年9月24日の1月22日・四国の調査では、公開用データと元の推定配列は一致していましたが、高知の「現象あり0cm」、松山・高松・徳島の「現象なし」という沿岸地点の区分を距離で山地へ広げ、石鎚山・剣山付近も0cm・現象なしとする問題が確認されました。日別の深さが近隣地点の0cmから山地まで0cmになり、現象区分の推定には標高が入っていません。変換・描画の取り違えではなく、元の推定法の制約であり、地点値が正しくても山地の分布の妥当性は保証されません。

「1cm以上のみ表示」は0cmを非表示にする表示フィルターです。この推定法や元データを直す機能ではなく、細かな雪域境界、とくに少雪域・山地を信頼できる状態にしたとは扱いません。標高・地形を考慮した再推定、根拠不足格子の欠測化と独立検証は未実施です。

## データと表示

- 道路：国土地理院「地理院地図Vector（試験公開）」の `road` レイヤー
- 背景：国土地理院「淡色地図」タイル
- 道路区分：`motorway`、`rdCtg`、`ftCode` を使った本ツール独自の表示区分
- 地図描画：MapLibre GL JS 6.10.0

地理院地図Vectorは試験提供で、URL、属性、データ構成が変更される場合があります。公式案内では2026年9月16日に全国データを2026年7月1日時点へ更新したとされています。

- https://maps.gsi.go.jp/development/vt.html
- https://maps.gsi.go.jp/development/ichiran.html
- https://www.gsi.go.jp/LAW/2930-index.html

国土地理院のデータをBousai Wx Labが独自に区分・着色して表示しています。国土地理院が本ツールの区分を作成・認定したものではありません。

## 通信とプライバシー

この版は、現在地、住所、自由入力、Cookie、Web Storage、アクセス解析を使用しません。表示状態を端末やURLへ保存しません。気温の表示用ファイル、積雪面ON時の冬季分、またはツールチップON時の選択日1件をGitHub Pagesから取得します。

地図を動かすと、表示範囲に応じたタイルを国土地理院へ直接要求します。この通信では、IPアドレス、要求したタイルURL、時刻、一般的な通信情報が配信元に伝わり得ます。GitHub Pagesへのアクセス情報はGitHub側の通信記録に残り得ます。

ブログとXには、利用者がヘッダーまたはフッターのリンクを押した時だけ移動します。
